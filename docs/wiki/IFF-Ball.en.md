# 🏐 Ball Specifications

*[🇩🇪 Deutsch](IFF-Ball.md) | 🇬🇧 English*

For the ball color on the field, you can choose from the official IFF
tournament colors, plus one additional option for street floorball:

| Color | Hex | Official (IFF) |
|---|---|---|
| Orange | `#f97316` | ✓ |
| Yellow | `#eab308` | ✓ |
| Pink | `#ec4899` | ✓ |
| White | `#ffffff` | ✓ |
| Black | `#1a1a1a` | ✗ (street floorball only) |

Per the IFF rulebook, the ball must contrast clearly with the field
surface – the default selection in the board editor already accounts
for this based on the chosen [theme](./Einstellungen.en.md).

# 🏷️ Systemvorlagen (Forechecking/Powerplay/Boxplay)

*🇩🇪 Deutsch | [🇬🇧 English](Systemvorlagen.en.md)*

14 eingebaute Formationssysteme im Taktikboard, unterteilt in drei
Kategorien. Die Vorlagen laden per Ein-Klick inkl. **automatischer
Feldtyp-Skalierung** (Pfostengeometrie, Spielfeld-Maße) und sind als
 Ausgangspunkt für eigene Anpassungen gedacht.

## Vorlagen

### Forechecking

| System | Beschreibung |
|---|---|
| 2-1-2 | Klassisches Forechecking mit zwei Stürmern weit vorn |
| 2-2-1 | Druck über zwei Reihen, ein Angreifer als Spitze |
| 1-2-2 | Ein Angreifer press oben, zwei Reihen dahinter |
| High Press | Aggressives Pressing im Angriffsdrittel |
| Mid Press | Pressing im Mittelfeld |
| Low Block | Defensive Formation im eigenen Drittel |

### Powerplay

| System | Beschreibung |
|---|---|
| 5v4 Umbrella | Überzahl-Spiel über den Point |
| 5v3 | Überzahlsituation im Angriffsdrittel |
| 4v3 | Überzahlsituation ohne Point-Spieler |
| 6v5 Empty-Net | Powerplay mit leerem Tor (Angriff) |

### Boxplay

| System | Beschreibung |
|---|---|
| Box | Klassisches Box-System (2+2) |
| Diamond | Raute als Aufstellung |
| Aggressiv | Pressendes Boxplay |
| Passiv | Abwartendes, tiefes Boxplay |

## Kategorie-Filter

Im Formationen-Tab gibt es einen **Kategorie-Filter**, mit dem die
Vorlagen nach Forechecking/Powerplay/Boxplay/Allgemein gefiltert
werden können. Beim Speichern eigener Formationen lässt sich ebenfalls
eine Kategorie zuweisen (optionale `category`-Spalte auf
`formation_templates`: `forechecking`/`powerplay`/`boxplay`,
NULL = Allgemein, abwärtskompatibel).

## Nutzung

1. Taktikboard öffnen → Tab "Formationsvorlagen"
2. Kategorie wählen (oder "Alle")
3. System per Klick laden → Spieler werden automatisch positioniert
4. Beliebig anpassen und als eigene Vorlage speichern

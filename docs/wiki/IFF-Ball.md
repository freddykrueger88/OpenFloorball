# 🏐 Ball-Spezifikationen

*🇩🇪 Deutsch | [🇬🇧 English](IFF-Ball.en.md)*

Für die Ball-Farbe auf dem Spielfeld stehen die offiziellen
IFF-Turnierfarben zur Auswahl, plus eine zusätzliche Option für Street
Floorball:

| Farbe | Hex | Offiziell (IFF) |
|---|---|---|
| Orange | `#f97316` | ✓ |
| Gelb | `#eab308` | ✓ |
| Pink | `#ec4899` | ✓ |
| Weiß | `#ffffff` | ✓ |
| Schwarz | `#1a1a1a` | ✗ (nur Street Floorball) |

Der Ball muss laut IFF-Regelwerk kontrastreich zur Feldfläche sein –
die Standardauswahl im Board-Editor berücksichtigt das bereits über
das gewählte [Theme](./Einstellungen.md).

# 🏒 OpenFloorball Wiki

*[🇩🇪 Deutsch](Home.md) | 🇬🇧 English*

Welcome to the OpenFloorball wiki! Here you'll find everything about
installation, usage, and development.

**OpenFloorball** is a self-hosted tactics tool for floorball coaches:
a virtual 2D field, animated plays (frame-by-frame), export as
GIF/MP4/PDF/link, Docker-based and IFF-compliant.

> 📌 Current version: **v0.9.0** – see [Changelog](./Changelog.en.md)
> for all changes and [Roadmap](./Roadmap.en.md) for what's planned.
>
> 📸 [Screenshots](./Screenshots.en.md) – field editor, training
> planner, community library, AI knowledge assistant, and more in
> pictures.

## Main features

- Virtual IFF-compliant field (large/small/street/3v3)
- Frame-by-frame animation with smooth interpolation, automatic
  versioning
- Drawing tools (movement/pass/shot arrows, freehand)
- Goalie tools (angle, rebound, counter, communication)
- System templates (14 built-in forechecking/powerplay/boxplay systems)
- Formation templates, playbooks
- Training planner, roster, lines, carpool (ridesharing)
- Player dashboard (daily/season overview, map to game venue)
- Live game notes, shot & goalie statistics
- Teams and clubs, news/announcements, polls
- Video integration (upload, drawing overlay, trimming, scene markers)
- Real-time collaboration (presence indicator, live cursors)
- Four optional AI assistants (training, tactics, analysis, knowledge)
- Community library for sharing exercises instance-wide
- Export as GIF, MP4, PDF, or public link; board sharing between users
- Generic audit log (compliance, who did what when)
- PWA/offline mode with conflict detection, 10 languages (DE, EN, SV,
  FI, CS, SK, NB, LV, PL, FR), accessible

## Current version: v0.9.0

The biggest release so far – seven new feature areas plus a complete
dependency/runtime modernization:

- **Formation templates** – save & reuse lineups
- **Playbooks** – group boards into collections
- **Training planner** – assemble boards into drill sequences
- **Central roster** – maintain players once, assign them everywhere
- **PWA/offline mode** – app shell + recently seen data available
  offline
- **Board sharing (MVP)** – share boards with other users
- Keyboard shortcut overview, visible undo/redo history, fully
  keyboard-operable drawing

Added since the release: optional [email delivery](./E-Mail-Versand.en.md)
for collaborator notifications, a reworked board editor menu (tab bar
instead of sidebar, see [First steps](./Erste-Schritte.en.md)).

Details, older versions, and every fix: see the linked `CHANGELOG.md`.

# 🏷️ System Templates (Forechecking/Powerplay/Boxplay)

*🇩🇪 [Deutsch](Systemvorlagen.md) | 🇬🇧 English*

14 built-in formation systems on the tactics board, split into three
categories. Templates load with a single click including **automatic
field type scaling** (post geometry, field dimensions) and serve as a
starting point for your own adjustments.

## Templates

### Forechecking

| System | Description |
|---|---|
| 2-1-2 | Classic forechecking with two high forwards |
| 2-2-1 | Pressure via two rows, one forward as the tip |
| 1-2-2 | One forward pressing high, two rows behind |
| High Press | Aggressive forechecking in the offensive zone |
| Mid Press | Forechecking in the neutral zone |
| Low Block | Defensive formation in the own zone |

### Powerplay

| System | Description |
|---|---|
| 5v4 Umbrella | Overload play through the point |
| 5v3 | Powerplay situation in the offensive zone |
| 4v3 | Overload without point player |
| 6v5 Empty-Net | Powerplay with empty net (attacking) |

### Boxplay

| System | Description |
|---|---|
| Box | Classic box system (2+2) |
| Diamond | Diamond formation |
| Aggressive | Pressing box play |
| Passive | Deep, waiting box play |

## Category Filter

The formations tab includes a **category filter** to filter templates
by forechecking/powerplay/boxplay/general. When saving your own
formations you can also assign a category (optional `category` column
on `formation_templates`: `forechecking`/`powerplay`/`boxplay`,
NULL = General, backward compatible).

## Usage

1. Open tactics board → "Formation Templates" tab
2. Choose a category (or "All")
3. Click a template to load it → players are automatically positioned
4. Adjust freely and save as your own template
